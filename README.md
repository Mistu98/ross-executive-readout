# Ross Video — Interactive Executive Research Readout

Interactive, Carleton University–branded executive presentation for the capstone **Risk-Based Assessment of AI-Assisted Software Engineering Activities**.

## Open the site

When GitHub Pages is enabled (Settings → Pages → Deploy from a branch → `main` / `/(root)`), the presentation is expected at:

https://mistu98.github.io/ross-executive-readout/

GitHub Pages may not be enabled merely because these files are committed.

## Presentation contents

- Executive overview and evolution of the project
- Four deliverables and the evidence supporting them
- Activity-level findings from A1 (bug fixing), A2 (Cloudbreak pilot), A3 (AI-assisted code review)
- What the research revealed about readiness, adequacy, and effectiveness
- Whetstone monitoring and evidence gaps
- Recommendations and a repeatable reassessment process

Use **Present** mode for the live meeting or **Explore** mode for browsing afterward.

## Technical details

The site is a single self-contained HTML file (`index.html`), with styles and JavaScript embedded. No build or external backend is required. The Carleton logo is embedded; the Ross Video logo is loaded from Ross's third-party hosted logo asset, with a text fallback if it cannot load.

## Confidentiality and research limits

**This repository and GitHub Pages site are public.** Share only with Ross's approval. This presentation summarizes project findings and does not constitute a validation of all Ross engineering controls or a production-ready automated risk assessment.
